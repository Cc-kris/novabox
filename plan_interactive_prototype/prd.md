# Novabox 可交互原型 PRD

- 节点评分：2/2
- 基线：`docs/V1.0/` 两份 V1.0 方案；本文件只定义本次原型，不扩展为桌面/MCP产品实施。
- 当前问题：已有品牌和产品规范，但无法直观体验核心闭环。
- 本次目标：交付可从浏览器打开、点击和验证的高保真单页原型。

## 需求清单

| REQ | 优先级 | 需求 | 依赖 |
|---|---|---|---|
| REQ-001 | Must | 工具库支持搜索、筛选、收藏、打开工具 | - |
| REQ-002 | Must | 通用示例工具支持结构化输入、校验、运行和结果复制 | - |
| REQ-003 | Must | 模拟 Agent 调用，自动填参、执行并显示来源 | REQ-002 |
| REQ-004 | Must | 草稿支持校验/测试状态、预览和确认发布 | - |
| REQ-005 | Must | 历史可查看运行快照并复用输入 | REQ-002 |
| REQ-006 | Should | 设置支持主题、侧栏宽度、宿主连接状态 | - |
| REQ-007 | Must | 320/360/720px布局、键盘、焦点和完整状态可用 | REQ-001~006 |

## 用户路径

- P-01：工具库 → 搜索/收藏 → 打开工具 → 输入 → 运行 → 复制结果。
- P-02：点击“模拟 Agent 调用” → 自动填参并执行 → 查看结果与来源。
- P-03：草稿 → 查看测试与权限 → 确认发布 → 工具库出现新工具。
- P-04：历史 → 查看快照 → 复用输入 → 回到工具。
- P-05：设置 → 切换深浅主题/宽度/宿主状态 → 界面同步。

## 状态与边界

空库、无搜索结果、运行中、成功、参数错误、执行失败、草稿校验失败、未连接、长文本均有界面；原型数据仅存于当前页面，刷新复位，不写后端。重复运行生成新历史；未发布草稿不可运行。所有按钮必须有效或明确 disabled 原因。

## 非目标

不实现真实窗口追随、真实 MCP、任意代码执行、账号、联网 API、文件上传和移动端 App。示例工具只证明通用模板能力，不代表业务范围。
