# 原型测试用例

- 编码前评分：2/2；执行证据由主session和独立验证补齐。

| TC | 场景与步骤 | 期望 |
|---|---|---|
| TC-001 | 打开首页，检索关键词、清空、无结果 | 列表正确过滤；空态可恢复 |
| TC-002 | 收藏/取消并切换筛选 | 状态和数量同步，无重复条目 |
| TC-003 | 打开工具，空必填运行，再合法输入运行 | 字段错误可见；成功结果与历史新增 |
| TC-004 | 运行中重复点击；触发模拟失败 | 防重入；错误保留输入且可重试 |
| TC-005 | 点击模拟Agent调用 | 自动填参、来源标记、执行结果可见 |
| TC-006 | 草稿查看测试，确认发布并打开 | 权限/测试可见；发布一次且可运行 |
| TC-007 | 历史打开快照并复用输入 | 数据一致并回工具页 |
| TC-008 | 设置主题/宽度/宿主断开 | CSS变量与布局同步，本地工具不阻断 |
| TC-009 | 320/360/760px与长文本 | 无水平溢出/重叠，关键操作可达 |
| TC-010 | Tab/Enter/Esc/dialog焦点/减少动效 | 键盘可用、焦点可见、关闭返回触发点 |
| TC-011 | 控制台、静态子资源、复制结果 | 无错误；资源非空；复制反馈有效 |
| TC-012 | 空库、加载、错误、禁用、无权限/长文本 | 各状态可触发且有明确界面 |
